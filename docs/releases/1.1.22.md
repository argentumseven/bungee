Download **bungee.apk** below for Android 12+ (ARM64 and x86_64). The app version is **1.1.22**, Android version code **38**. This is the official persistent-key APK; GitHub and your Bungee server distribute the same signed file.

## Changes

- Photo uploads use their intended 60-second budget instead of the shorter control-request budget.
- A transient runtime conflict pauses camera capture and reports why, without silently withdrawing local camera consent.
- Profile/camera capabilities refresh on the next sync. Picture readiness uses server time consistently, and old duplicate-instance notices no longer block it indefinitely.
- Shared hardware commands report when the main Android user was in the background; the dashboard shows a matching warning.

## Install or update

Start with the [home-server installation guide](https://github.com/argentumseven/bungee/blob/main/docs/INSTALL.md) for dependencies, router ports and HTTPS trust. Update the server first, then the matching APK. For the source workflow, run this on your server:

```sh
cd /usr/local/src/bungee &&
git pull --ff-only origin main &&
sudo python3 scripts/bungee-host.py rebuild &&
sudo python3 /opt/bungee/bungee-host.py status
```

Change paths for a custom installation. Pulling Git alone does not replace the running containers or dashboard. Rebuild preserves configuration, pairing and history, creates an encrypted snapshot, and checks the candidate with rollback on failure. The optional published-container update channel is a separate path.

Routine official APK upgrades retain pairing and app data; Android asks for installation confirmation. Do not uninstall for a routine update. Historical disposable-key installations need the documented one-time signing-identity migration; see [phone updates and recovery](https://github.com/argentumseven/bungee/blob/main/docs/MANAGEMENT.md).

Verify `bungee.apk.sha256`; `build.json` records the source, version, checksum and signing certificate. APK bytes are unchanged by release-page cleanup. Camera access still requires local approval in the active profile. Read the [security design](https://github.com/argentumseven/bungee/blob/main/docs/SECURITY.md) and [validation limits](https://github.com/argentumseven/bungee/blob/main/docs/VALIDATION.md); automated checks are not an independent audit or physical-device acceptance test.
